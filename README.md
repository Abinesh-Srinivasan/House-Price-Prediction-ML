# House Price Prediction
##Linear Regression 

This project focuses on predicting house prices in Boston using Machine Learning. It serves as a foundational step in my journey to understanding and implementing ML concepts.  

---

## Project Overview  

- Built a **Boston House Price Prediction Model** using **XGBRegressor**.  
- Gained hands-on experience in applying fundamental ML concepts and evaluating model performance.  

---

## Tools & Technologies  

- **Python**: Programming language for implementation.  
- **Pandas**: For data analysis and manipulation.  
- **Matplotlib & Seaborn**: For data visualization using heatmaps and graphs.  
- **Scikit-learn**: Used for splitting data and calculating evaluation metrics.  
- **XGBoost**: Implemented **XGBRegressor** for regression modeling.  

---

## Key Features  

1. **Dataset Handling**: Imported, cleaned, and prepared the Boston Housing dataset for modeling.  
2. **Exploratory Data Analysis (EDA)**: Visualized feature relationships and correlations using heatmaps.  
3. **Model Implementation**: Applied **XGBRegressor** for training and prediction.  
4. **Evaluation**: Assessed model performance using:  
   - **Mean Absolute Error (MAE)**  
   - **R-Squared Error (R²)**  

---

## Learning Outcomes  

- Gained insights into the process of **data preprocessing** and **EDA** for better understanding of datasets.  
- Learned the implementation and evaluation of models using **XGBRegressor**.  
- Understood how to interpret metrics like **MAE** and **R-Squared Error** to assess model accuracy.
